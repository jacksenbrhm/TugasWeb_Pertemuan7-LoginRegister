# 🔐 Tugas Rutin 7 — Sistem Login/Register PHP Native

Tugas mata kuliah **Pemrograman Web** — FMIPA UNIMED — Semester Ganjil 2026/2027.

## 📋 Fitur

- ✅ Registrasi dengan validasi (nama, email, password)
- ✅ Validasi email dengan `filter_var()`
- ✅ Password di-hash dengan `password_hash()`
- ✅ Penyimpanan data di file JSON
- ✅ Cek duplikasi email
- ✅ Login dengan session
- ✅ Dashboard terproteksi
- ✅ Logout dengan `session_destroy()`
- ✅ Sanitasi input dengan `htmlspecialchars()`
- ✅ Pesan error & sukses
- ⭐ Bonus: "Remember Me" dengan cookies aman (token random)
- ⭐ Bonus: Halaman edit profile
- ⭐ Bonus: Tampilan CSS rapi & responsive

## 🛠️ Teknologi

- PHP Native 8.x
- JSON sebagai database
- Session & Cookies
- HTML5 + CSS3
- XAMPP (Apache)
